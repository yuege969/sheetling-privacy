# sheetling-privacy

**这个仓库现在只做一件事：把旧地址跳到产品站点的隐私页。**

- 跳转目标：<https://sheetling.aixcp.com/privacy.html>
- 主地址（唯一全文）：<https://sheetling.aixcp.com/privacy.html>
- 单一真源：私有仓库 `sheetling` 的 `store/privacy.html`；站点由 `npm run site:publish` 生成。

为什么保留它：Creem 的审核不接受免费托管子域，所以主地址必须在自有域名下；
但这里必须继续可访问——它是"零权限 / 零出站"这条主张的公开可核对副本，
也是域名万一出问题时的兜底地址。**不要再往这里写第二份全文。**
