# sheetling-privacy

Sheetling（PDF 转 Excel · 本地处理）Chrome 扩展的隐私政策托管页。

- 页面：<https://yuege969.github.io/sheetling-privacy/>
- 唯一真源在私有仓库 `sheetling` 的 `store/privacy.html`；本仓库的 `index.html` 与这份 README
  都由 `tools/publish-privacy.mjs` 生成（`npm run privacy:publish`），**请勿直接编辑**。
- 本仓库只有这一个静态页面，不含任何脚本、统计或 Cookie。
